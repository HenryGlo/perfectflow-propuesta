# PerfectFlow — propuesta de landing (v2)

Propuesta de diseño para la landing de PerfectFlow, construida por Code Flakes LLC.
HTML, CSS y JS estáticos, sin build ni frameworks.

- `index.html` — la página completa (ES/EN).
- `assets/brand/` — logo oficial (imagotipo, isotipo, favicon) según el manual de marca.
- `assets/fonts/chillax-variable.woff2` — Chillax (Indian Type Foundry, Fontshare · ITF Free Font License).

Es una propuesta: la página lleva `noindex` para no competir en buscadores con perfectflow.cloud.
Las cifras del panel de reportes y los testimonios son de ejemplo y están marcados como tales.
